## 平台概览

DiffDynamic 是面向 **3D 结构化药物设计（SBDD）** 的扩散模型推理框架。在 [TargetDiff](https://github.com/DeepGraphLearning/TargetDiff) 基础上，通过推理阶段优化显著提升生成分子的质量与多样性。

> **Paper Demo** — 本界面用于论文演示与实验复现。支持分子生成、口袋质量评估、对接评估、结果提取与历史追溯，所有操作均持久化记录。

---

## 核心创新

### 1 · 两阶段动态跳步采样

**AIDD 领域首创。** 扩散去噪轨迹中，不同时间步的信息密度差异巨大——高噪声区确定拓扑、低噪声区精修几何。DiffDynamic 据此将采样分为「大步跳跃」与「精细修复」两阶段，配合结构修复机制，在保持质量的同时 **节省约 60–70% 神经网络评估**。

| 阶段 | 时间范围 | 目的 |
|------|----------|------|
| 大步跳跃 | t=999 → t_boundary | 拓扑探索，自适应大步长 |
| 精细修复 | t_boundary → 0 | 几何精修，密集小步长 |

### 2 · 梯度融合

在每个去噪步骤混合 **局部后验梯度** 与 **全局 x₀ 预测梯度**，λ(t) 从 1.0 衰减至 0.0——早期建立整体构象，后期精修键级几何。支持 quadratic、linear、exponential、adaptive、time 五种调度。

### 3 · Prudent 多轮过滤

将属性过滤嵌入扩散过程内部，实现 **生成 → QED/SA 门控 → Vina 对接 → Top-K 保留** 的闭环。QED/SA 门控避免对低质量分子运行昂贵对接，大幅节省计算。支持**自适应门控**（根据参考配体性质自动放宽/收紧阈值）。

### 4 · 骨架约束生成（四种模式）

| 模式 | 说明 |
|------|------|
| **Grow（生长）** | 固定 Murcko 骨架原子，在口袋内生长额外侧链/片段 |
| **Evolve（进化）** | SDEdit 噪声退火 + 种群进化，逐步改整个分子 |
| **Dynamic Locked（锁定）** | 锁定骨架原子类型与坐标，维持骨架不变 |
| **Prudent（谨慎）** | 骨架约束 + 多轮属性过滤 + 对接驱动晋级 |

骨架可从 SDF/PDB 自动提取（Murcko / 通用骨架），也可手动指定原子索引或 SMARTS。支持 **ScaffoldCascade 级联**：多轮随机化参数合并结果，提升多样性与质量。

### 5 · 口袋质量多维评估

对生成结果执行 8 维综合评估：

A · Vina 对接 + 配体效率 · B · 原子聚类 · C · 配体效率 · D · 药物相似性 · E · 完整分子比例 · F · 分子唯一性 · G · 尺寸一致性 · H · 口袋体积

> 结果含雷达图与口袋可视化图像。

### 6 · 多维分子评分

综合 Vina 亲和力、QED、SA、Lipinski 与 Lilly Medchem Rules（PAINS 过滤），输出 0–100 综合评分，支持多维度筛选与排序。

## 创新定位

| 组件 | 新颖性 | 要点 |
|------|--------|------|
| **动态跳步采样** | AIDD 首创 | 拓扑/几何解耦，信息密度驱动步长分配 |
| **梯度融合** | 新颖公式 | 后验均值与 x₀ 方向混合，5 种调度 |
| **Prudent 过滤** | SBDD 扩散首创 | 扩散内属性门控 + 对接驱动选择 |
| **骨架生成** | 工程贡献 | Murcko 检测 + 生长/进化/锁定/谨慎 4 模式 |
| **级联生成** | 工程贡献 | 多轮随机化合并，多样性与质量双提升 |

## 使用指南

| 页面 | 功能 |
|------|------|
| **分子生成** | Dynamic 快速采样 / Prudent 多轮优化 / 预设配置，支持自动评估与提取 |
| **骨架生成** | Grow / Evolve / Dynamic Locked / Prudent 四种模式，自适应门控 |
| **骨架级联** | 多轮随机化参数 Gow 生成并合并结果 |
| **分子优化** | 从种子分子出发逐步优化 QED/SA/Vina |
| **评估提取** | 对 `.pt` 结果运行 Vina 对接与化学指标评估，导出 SDF/Excel |
| **口袋评估** | 8 维口袋质量评分 + 雷达图 + 可视化图像 |
| **分子数据库** | 按口袋、SMILES、Vina 评分等条件搜索已评估分子 |
| **历史记录** | 查看全部操作日志，追溯参数、结果摘要并支持一键重跑 |
| **系统配置** | 编辑 `sampling.yml`、查看 GPU 状态 |

**推荐工作流：** 上传/选择蛋白-配体 → 选择模式生成（batch_size=5 测试）→ 自动评估 → 自动提取 → 查看口袋评估/分子数据库，全部操作自动记录到历史。

## 运维说明

- 服务监听 `0.0.0.0`，多用户并发经任务队列调度。
- 所有生成/评估/提取任务异步后台执行，可实时查看进度并取消。
- 运行记录、分子目录、评估结果持久化于 SQLite（`diffdynamic.db`），重启后完整保留。
